Upgrade notes:
  nodes are stateless and can be rolled; database migrations run idempotently at node startup (forward-only, ⑥ §8).
  before rolling back, confirm the migration is compatible with the old version (destructive migrations must use the expand/contract two-phase approach).
  after TLS certificate rotation, node/web must be restarted with a rollout to reload them (certificates are read at process startup).
